How It Works

  1. Import your existing portfolio.json or start fresh.
  2. Navigate to each section using the sidebar and edit your content.
  3. Auto-save: Go to GitHub Settings in the sidebar, enter your Personal Access Token, then click "Save & Deploy" — changes go live automatically!
  4. Manual: Click "Export portfolio.json" to download, replace the file in your repo, commit & push.

GitHub Personal Access Token

To enable Save & Deploy, you need a GitHub Personal Access Token with repo scope. Your token is stored only in your browser's localStorage — it never leaves your machine.

  1. Go to GitHub → Settings → Developer Settings → Personal Access Tokens → Tokens (classic)
  2. Click "Generate new token (classic)"
  3. Give it a note like "Portfolio Admin", select the repo scope
  4. Copy the token and paste it above
